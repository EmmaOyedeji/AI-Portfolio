## 🚀 Featured Projects

### 🎸 01 — BassStart: AI-Assisted Bass Learning Website

BassStart is an interactive bass-guitar learning website developed
through an AI-assisted development workflow.

The platform provides a structured learning experience covering bass
technique, fretboard knowledge, music theory, grooves, styles, and
practical musicianship.

**What I Did:**
- Defined the website concept and requirements
- Used structured prompts to guide AI-assisted development
- Iteratively reviewed and refined generated outputs
- Designed the learning experience and content structure
- Tested and improved the website
- Deployed the finished website using Netlify

**Skills Demonstrated:**

`AI-Assisted Development` `Prompt Engineering` `Requirements Design`
`Iterative Development` `Web Development` `Testing` `Deployment`

### 🧠 02 — User-Friendly Bass Guitar Instructor AI Skill

Designed a custom AI skill that transforms an AI assistant into a
structured bass-guitar tutor and practice coach.

The skill uses a seven-part framework:

1. Trigger
2. Input
3. Sources
4. Workflow
5. Decision Rules
6. Output
7. Validation

The skill is designed to adapt AI instruction according to factors such
as the player's skill level, bass type, genre, gear context, and
requested output format.

**Skills Demonstrated:**

`AI Instruction Design` `Prompt Engineering` `Workflow Design`
`Decision Rules` `AI Behavior Design` `Validation`
