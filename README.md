### 🧠 02 — Bass Guitar Instructor: Custom AI Skill

Designed and tested a reusable AI skill that transforms an AI assistant into a structured bass-guitar instructor and practice coach.

Rather than relying on a single prompt, the skill defines how the AI should interpret player context, select an instructional approach, follow a teaching workflow, apply decision rules, structure its responses, and validate output quality.

The skill adapts instruction based on factors including:

- Player skill level
- Number of strings
- Musical genre
- Existing knowledge
- Practice goals
- Available practice time
- Technique or topic
- Requested output format

**Skill Architecture:**

`Trigger` → `Input` → `Sources` → `Workflow` → `Decision Rules` → `Output` → `Validation`

**Skills Demonstrated:**

`AI Skill Design` `Prompt Engineering` `Context-Aware AI` `Decision Rules` `Workflow Design` `AI Evaluation` `Testing` `Validation`

### 🧪 Testing & Evaluation

The AI skill was tested across three different player profiles:

| Test | Player | Primary Focus |
|---|---|---|
| 01 | Beginner | Basic timing, fretboard notes and simple gospel grooves |
| 02 | Intermediate | Fills, fretboard navigation, drummer interaction and musical restraint |
| 03 | Advanced | Jazz improvisation, voice leading, chromaticism and rhythmic phrasing |

Testing demonstrated that the skill changes instructional complexity according to the player's experience and goals while also revealing opportunities for further improvement.
