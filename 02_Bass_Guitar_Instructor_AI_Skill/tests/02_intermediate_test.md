# Test Case 02 — Intermediate Gospel Bass Player

## 🎯 Test Objective

Evaluate whether the Bass Guitar Instructor AI Skill adapts its
instructional approach for an intermediate player and produces more
advanced, context-specific instruction than the beginner test.

---

## 👤 User Context

| Variable | Value |
|---|---|
| Skill Level | Intermediate |
| Instrument | 5-string bass |
| Genre | Gospel |
| Practice Time | 30 minutes per day |
| Existing Knowledge | Basic scales, major/minor arpeggios, common chord progressions |
| Primary Challenges | Fills, fretboard navigation, timing with drummer, musical restraint |
| Goal | Develop tasteful and rhythmically appropriate gospel fills |
| Requested Output | 7-day practice plan |

---

## 📝 Test Prompt

> I'm an intermediate bass player using a 5-string bass.
>
> I mainly play gospel music and already understand basic scales,
> major and minor arpeggios, and common chord progressions.
>
> I can practice for 30 minutes a day.
>
> My biggest challenges are:
> - creating tasteful fills between chords,
> - moving around the fretboard without getting lost,
> - keeping my fills in time with the drummer, and
> - knowing when NOT to play a fill.
>
> Create a 7-day practice plan to improve these areas.
>
> Include practical gospel examples, suggested metronome tempos,
> fretboard exercises, and specific exercises for developing fills.

---

## ✅ Validation Results

| Criterion | Result | Observation |
|---|---|---|
| Appropriate for intermediate level | PASS | Exercises move beyond beginner fundamentals into fills, position shifts, targeting, and drummer interaction. |
| Respects available practice time | PASS | Each day totals exactly 30 minutes. |

| Addresses fretboard navigation | PASS | Position shifting, fretboard mapping, and connecting positions are included. |
| Addresses timing | PASS | Metronome tempos, subdivisions, drum locking, and fill timing are incorporated. |
| Addresses musical restraint | PASS | Musical restraint and fill/no-fill decisions are explicitly included. |

---

## 🔍 Issues Identified

The test demonstrated successful adaptation from beginner to intermediate
instruction, but several opportunities for improvement remain:

1. The response recognizes the player's intermediate level but does not
   fully explain how to execute each exercise.

2. The user specifically identified a 5-string bass, but the exercises
   do not explicitly incorporate the low B string.

3. Gospel-specific concepts are included, but practical note-by-note
   examples could make the exercises more actionable.

4. "Knowing when not to play" is addressed through musical restraint and
   fill/no-fill decisions, but the skill could provide clearer decision
   rules for choosing when to leave space.

---

## 🔄 Comparison with Test Case 01

The skill demonstrated meaningful adaptation between the beginner and
intermediate tests.

### Beginner Test

Focused on:

- Open strings
- Basic note learning
- Quarter and eighth notes
- Root–5th patterns
- Simple gospel grooves

### Intermediate Test

Focused on:

- Chord-to-chord fills
- Rhythmic vocabulary
- Position shifting
- Target-note fills
- Pentatonic and blues vocabulary
- Drummer interaction
- Musical restraint
- Fill/no-fill decisions

This difference provides evidence that the skill changes its
instructional approach according to player experience and stated goals.

---

## 💡 Recommended Skill Improvements

Future versions of the skill should encourage the AI to:

- Provide step-by-step execution instructions for exercises.
- Explicitly incorporate extended-range strings when the player uses
  a 5- or 6-string bass.
- Provide concrete note or fret examples for genre-specific exercises.
- Explain when a fill should and should not be played.
- Include measurable success criteria before increasing difficulty.

---

## 📊 Test Conclusion

The skill successfully adapted its response to an intermediate gospel
bass player.

Compared with the beginner test, the response increased the technical
and musical complexity while maintaining the requested practice-time
constraint.

The test also identified opportunities to improve exercise specificity,
extended-range bass utilization, and actionable musical examples.
